# anime-reviews (AI-SOURCES: Anime)

このリポジトリは、**ひらりん / ヒラリラー**が[note](https://note.com/hirarira617)で公開している「アニメの毎日感想」を、生成AIでの処理（RAG、LLM学習、データ分析など）に最適化するためにMarkdown形式に変換・ホストしているデータ置き場です。

## 📌 概要
* **元ソース**: [ひらりん / ヒラリラー｜note](https://note.com/hirarira617)
* **データ形式**: Markdown (.md) 形式（生成AIのパース精度向上のため、テキストデータ主体の構成に最適化しています）
* **内容**: 日々視聴したアニメのリアルタイムな感想・評価データ

## 🤖 生成AIでの利用・データ解析について
本リポジトリの**テキストデータ（感想本文）**は、生成AI（LLM）のプロンプト、RAG（検索拡張生成）の参照ソース、トレンド分析、統計処理などのインプットとして**自由にご活用いただけます**。

**重要：画像について**
Markdown内に埋め込まれている画像は、すべてnote上のオリジナル記事から転載された**アニメのキャプチャ画像**です。  
これらの画像の著作権は各アニメの権利者（制作会社・出版社など）に帰属しており、本リポジトリの作者は一切の権利を保有していません。

そのため、以下を厳守してください：
- 画像のダウンロード・保存・再配布・二次利用は**禁止**します
- AI処理・解析を行う際は、**画像を完全に除外（削除または無視）し、テキストのみを使用**してください
- 大量のMarkdownを読み込む際に画像URLへのアクセスが発生すると、note側のサーバーに不要な負荷をかける可能性があります
